# HimNet 三尺度冻结读出：第一轮结果

固定修正版 Full seed 0 编码器，在原 Lipo 3360/420/420 划分上比较预测头。五个种子仅改变预测头训练；不是五个编码器，也不是五个独立划分。

共完成 65 次训练；每次按验证集选模、严格重载后测试一次。编码器来源训练使用过指纹和辅助对齐；本轮预测头不接入指纹。历史测试结果已被查看。

## 与历史约 0.7 的结果区别

同一来源 checkpoint 的原完整 HimNet（seed 0）测试 RMSE 为 **0.714437**。该数值由已保存测试预测重算，没有重新执行模型测试。测试行号与标签和本轮一致。

| 项目 | 原完整模型 | 本轮 ASG 冻结探针 |
|---|---|---|
| 原子/Motif/全图编码 | 原有双路径 | 固定同一训练后编码器 |
| 图读出 | 全部节点按数量平均，再输出映射 | 各类节点先平均并分别映射，再拼接 |
| 指纹预测支路 | 保留 | 不接入预测头 |
| 融合与预测头 | 原有融合和联合训练头 | 新 MLP 重新训练 |
| 训练方式 | 完整模型联合训练 | 仅训练预测头 |

因此 0.9461 不是原完整 HimNet 的复现值，也不能把 0.7144→0.9461 的差异全部归因于冻结或删除指纹。本轮改变了多项预测端条件，缺少逐项匹配对照。三尺度分组名称相同不代表模型计算图相同。

此前汇总遗漏这条原模型参考；现补充此对照边界。已完成的 65 次运行保留为冻结读出探针，不能改称原模型七组消融。

无 Motif 分子计数：{'train': 117, 'valid': 25, 'test': 18}。无 Motif 时 S 固定为零向量。

A/S/G 来自已经完成跨尺度交互的节点状态；A 不是删除其他节点后的原子模型。本轮结论限于节点尺度输出的预测价值与互补性。整体节点表示、原子汇聚和 Motif 汇聚不应被解释为彼此独立的信息来源。
