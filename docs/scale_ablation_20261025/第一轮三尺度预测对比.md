# HimNet 第一轮三尺度读出对比

日期：2026-10-25。用户已确认模型为 HimNet。状态：已实现独立读出接口并通过合成输入检查，未修改上游文件，尚未运行本轮真实数据实验。本文替代先前自行设计 BRICS、全图查询和 GINE 四层的方案。

## 实验边界

保留 HimNet 原有层级图、原子/Motif/全图节点、双路径编码及尺度间交互，只改变参与预测的读出。比较 A、S、G、AS、AG、SG、ASG。A 表示只使用原子节点读出，不表示传播过程只使用原子信息。

## 源码定位

- research_code_audit/HimNet/dataset/loader.py：按原子、Motif、全图节点排列，num_part=[n_A,n_S,1]。Motif 初始特征是作者分组内原子特征之和，全图节点初始特征是全部原子特征之和。沿用作者分解。
- research_code_audit/HimNet/dataset/featurization.py：a_scope 是扩展节点范围，mol_atom_num 是真实原子数；不能将 a_scope 长度当成原子数。
- research_code_audit/HimNet/model/module/HGNNEncoder.py：消息传递后在分子内注意力更新，最终对全部扩展节点平均。
- research_code_audit/HimNet/model/module/ExplainableCrossAttentionEncoder.py：另一路由初始节点投影和注意力形成节点状态，再平均；两路图向量相加后经过 output_layer、ReLU、dropout。
- research_code_audit/HimNet/model/HimNet.py：图表示还与指纹支路融合后预测。

以上为本地源码核对，不冒充论文全文复核。

## 三尺度接口

令 p_i 为 HGNNEncoder 中 cur_hiddens+att_hiddens，即最终平均之前的节点状态；q_i 为另一路 enhanced_atom_features，两者对应相同扩展节点。

对每种节点类型 t∈{A,S,G}：

    p_t = mean(p_i : i 属于 t)
    q_t = mean(q_i : i 属于 t)
    z_t = ReLU(output_layer(p_t + q_t))

复用同一个 output_layer，不复制编码权重。冻结时 eval 禁用 dropout；G 只有一个节点，均值就是该节点状态。这是新增分尺度读出接口，不是原模型现成返回的三个向量。

切片依据 a_scope 起点及 num_part 真实计数，排除 padding，断言 n_A+n_S+1 等于分子扩展节点数。不得按 a_size//3 推测。

没有 Motif 时，最终 z_S 直接设为固定零向量，不通过带 bias 的映射，不复制 A/G，不构造可训练假 token。保留所有样本，报告无 Motif 数量；S 组在这些样本上的预测只能依赖预测头偏置等。

## 保留原计算图的验收

    p_all = (n_A*p_A + n_S*p_S + p_G)/(n_A+n_S+1)
    q_all = (n_A*q_A + n_S*q_S + q_G)/(n_A+n_S+1)

将 p_all+q_all 送入原 output_layer、ReLU、dropout，应在 eval 下恢复原图向量。z_t 经过非线性，不能要求 z_A/z_S/z_G 加权平均恢复原向量。原完整图向量混合全部节点，不能直接叫作 G。

## 预测端与指纹

七组使用对应 z 或其拼接，接同类型 MLP，首轮不新增 selector。主表不向预测头加入指纹，以隔离三种节点读出的作用，明确命名为图读出诊断，不能称完整原版 HimNet 流程。

含指纹原版可作单独参考行。冻结编码器若在来源训练中使用过指纹或辅助对齐，须披露；不加入指纹预测头不意味着表示训练未受指纹影响。后续保留指纹验证时，七组采用一致支路与融合规则，另表报告。

## 冻结与训练

先选定来源可追溯的完整 HimNet checkpoint：训练集拟合、验证集选模，不使用测试标签。七组共享同一编码器，eval 后缓存 z_A/z_S/z_G，冻结全部编码参数，只训练预测头。若来源为下游监督训练，命名为任务适配编码器上的探针实验；随机初始化冻结不能代替训练后表示。

小样本验收固定使用 him_repaired_pairs_3seeds_20261019/him_seed0/full_best.pt，以及该运行对应的修正版 HGNN 源码和显式双向层级图缓存。选择 seed 0 不依据成绩。该编码器受下游 Lipo 标签、指纹支路和辅助对齐训练影响，属于任务适配编码器。正式多种子探针配置尚未锁定，不将小样本参数视作正式调参结果。

后续端到端验证保持原图、编码层数、共享初始权重、预算和损失规则一致。辅助对齐若依赖原完整图向量，各组统一保留该辅助路径；不能随着预测子集改变对齐对象。

## 容量与配对

先固定预测头隐藏宽度并报告实际参数。再按每个组合的预测头参数预算，为其组成单尺度配置更宽预测头，匹配有效可训练参数，目标误差不超过 1%，否则披露实际差异；闲置参数不计入有效容量。

AS 对比 A/S，AG 对比 A/G，SG 对比 S/G；ASG 对比三个单尺度及三个双尺度。配对采用相同样本、划分、标准化、seed、数据顺序、预算和验证选模准则。报告逐 seed RMSE、均值、标准差、配对差值、参数、轮次和耗时。同划分多 seed 只衡量训练波动。

## 实施顺序

1. 固定源码版本与哈希。原版 HGNN 键注意力跨批分子计算；本地已有分子内注意力修复版，两版本不得混用或将修复收益归于尺度读出。原版缓存须固定批组成，修复版须验证 eval 分批不变性。
2. 暴露双路径节点状态，按真实节点计数读出，验证可恢复原完整图向量。
3. 训练/验证小样本覆盖有/无 Motif、不同分子大小与 padding，检查有限值和索引。
4. 验证冻结参数及 buffer 不变、预测头梯度有效、七组编码器哈希和缓存行号一致。
5. 完成小样本训练、验证选模、保存及严格重载，再锁定正式配置。冒烟不读取测试成绩。

结论限定为固定 HimNet 编码器下的节点尺度输出预测价值与互补性，不能直接解释为物理因果贡献。结构删除、传播层数和自适应选择留到后续。
