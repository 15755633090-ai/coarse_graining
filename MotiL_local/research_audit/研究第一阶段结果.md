# MotiL 优化研究：第一阶段结果

日期：2026-10-09。完成内容：原始基序选择逻辑的可执行诊断、实例保留与连接元数据原型、作者检查点推理验证。未进行优化器更新或性质指标训练。

## 确认的实现问题

1. 官方 `featurization.py:146–153` 对每类仅取 `fgs_tuple[0]`，丢弃同一分子中的其它匹配。
2. `BatchMolGraph` 仅在类型尚不存在时写入，不追加其它分子的同类实例，达到十类后停止扫描。因此基序分支的训练样本选择依赖 batch 顺序。
3. `cmpn.py` 基序分支 `for depth in range(depth - 1)` 覆盖函数参数。默认 depth=3 时，第一次循环结束后 depth=1，后续基序不再进行该循环。其深度依赖遍历顺序。

这些是当前公开实现的问题，不能直接归因于论文数学目标，也不能证明发布权重的具体历史训练过程。修复实现问题本身与提出方法创新必须分别报告。

上一份报告把编码器支持的同类型平均描述成实际汇集全部实例，表述不完整。本轮检查发现这些实例在进入编码器前已被筛掉，已在原报告顶部更正。

## 无标签全数据结构统计

使用官方官能团词表、原有“匹配超过一个原子”的资格规则和 RDKit 默认匹配枚举上限。不读取性质标签。重叠的 SMARTS 匹配仍作为不同实例，并不是不相交区域划分。

| 数据集 | 有效分子 | 枚举出的合格实例 | 单分子原选择保留 | 有重复类型的分子 |
| --- | ---: | ---: | ---: | ---: |
| ESOL | 1128 | 2793 | 1639 | 420 |
| BBBP | 2039 | 9168 | 5218 | 1142 |
| ClinTox | 1478 | 7445 | 3675 | 884 |
| BACE | 1513 | 9485 | 5850 | 1236 |
| Lipo | 4200 | 21021 | 11531 | 2934 |

例如，ESOL 单分子步骤丢掉约 41.3% 的合格实例；Lipo 约 45.1%。这只是实例保留统计，不能解释为预测信息损失比例。

按文件顺序以 16/32/64 组批的统计也已保存。ESOL 在审计 batch size=32 时最终保留 347 个，约为全部实例的 12.4%；Lipo 保留 1277 个，约 6.1%。这是固定顺序的结构诊断，不是作者预训练过程统计，更不是预测成绩。

两分子示例倒换 batch 顺序后，Carbonyl 与 Carboalkoxy 的实例来源随之改变，证明选择受顺序影响。

## 已实现的原型

`motif_instances.py`：

- 保留每个枚举出的合格实例，并保留分子 ID、类型、原子身份。
- 记录内部键、边界原子与跨区域连接端点。
- 区分实例重叠关系与真实化学桥接键，避免把重叠直接当作化学键。
- 显式列出未被词表覆盖的原子，不把基序视为完整分子分区。
- 复用现有 CMPNN 单实例编码和作者权重，不增加可训练参数；每个实例使用相同指定深度。暂时保留原有 padding mean，避免同时改变所有因素。

这是诊断用原型，逐实例调用速度较慢，尚未接入完整预训练损失或性质预测头；连接图目前是可用元数据，没有训练区域传播模型。

## 推理验证

运行 `verify_instance_encoder.py`，严格载入作者检查点全部参数，CPU、dropout=0，无训练。hidden size=300、depth=3、ReLU、bias=False 来源于现有公开默认设置，不是新的性质训练参数。

- 两分子示例原基序输出为 `[2,300]`，实例保留输出为 `[6,300]`。
- 对相同实例单独调用旧路径与新接口，最大绝对误差为 **0**。
- 反转 batch 后，按实例身份对应的表示最大绝对误差为 **0**。
- 全部输出为有限值。
- 原多类型连续调用与统一深度单实例调用的最大差为 **0.573655**，对应上面的 depth 覆盖问题。这是表示差异，不是性质指标提升。

验证程序还检查完整实例数、合法原子索引、已知链结构的连接端点和重叠关系。证据在两个 JSON 中。

## 锁定基线与后续消融

现有作者检查点 SHA256：`38082cdccb14a7d1b2749181548a81253e70196940bf979ef0f983b3a47e0f78`。来源验证在 `../official_checkpoint_verification.json`。已有四任务公开参数与运行命令在 `../paper_runs_verified_rng_20261008/manifest.json`；原结果不覆盖。

研究比较应区分：

| 版本 | 改动 | 解释 |
| --- | --- | --- |
| B0 | 原公开选择、原基序深度行为 | 保留作者公开实现作为参照 |
| B1 | 仅修正基序 depth 变量覆盖 | 单独量化实现修正 |
| B2 | B1 + 全实例保留；仍按类型汇总 | 检验实例选择截断的影响 |
| I1 | B2 + 保留实例身份与实例级目标 | 检验过早类型汇总 |
| I2 | I1 + 边界/连接端点编码 | 检验真实结构信息增量 |
| I3 | I2 + 基于化学连接的实例间传播 | 最后检验区域交互 |

扩散公式修正需要独立实验轴，不能同时加入 B1–I3 后把收益都归给基序方法。现有作者预训练权重只能支持下游起点，不能替代重新预训练来验证新的基序目标。

当前可下结论：实例截断与顺序依赖存在，实例保留接口能在这台电脑运行。当前不可下结论：这些问题导致论文指标变差，或本改进优于 MotiL。新的预训练规模、确切调度与任务协议尚未锁定，未启动不明确参数的长训练。
