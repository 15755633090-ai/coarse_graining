# MotiL 论文、公开实现与研究方向核对

核对日期：2026-10-09。范围：论文正文、已下载补充材料、官方仓库当前 main 的小分子实现，以及本项目现有 H1/H4 实验记录。没有恢复训练，没有新增参数搜索。

**后续诊断修正：** 继续检查 `featurization.py` 并执行官方选择逻辑后，发现单分子每类仅保留首个匹配，组批又仅保留首个出现的类型且最多十类。因此下文“同类实例平均”只描述编码器支持的聚合算子，实际输入构建并没有把全部实例送进去。另发现基序分支循环覆盖 `depth`，导致后续基序传播深度变化。以同目录 `研究第一阶段结果.md` 和诊断 JSON 为最新证据。

## 结论

上传分析中的研究问题值得检验，但不能把假设直接写成 MotiL 已被证实的缺陷。最需要修正的是：公开实现的扩散分支与论文公式存在明显差异；分子分支有全分子双向 GRU，不能仅用消息传递层数断言整体编码器的感受野；现有五个 head seeds 不是五个独立编码器或数据划分。简单增加 H1+H4、区域 GNN 或区域注意力，单独作为方法创新的依据不足。

## 1. 论文与公开代码

论文：[Molecular Motif Learning](https://www.nature.com/articles/s41467-025-66685-w)。官方代码：[Young0222/MotiL](https://github.com/Young0222/MotiL)。本次核对使用 `research_audit/upstream/` 中重新下载的官方文件，避免把本机兼容性补丁当作作者原始实现。这是 main 快照，未取得对应提交号；不能据此断言发布权重究竟由哪个历史版本生成。

### 1.1 扩散目标存在实质差异

论文 Diffusion priming 描述对邻接矩阵加高斯噪声、编码加噪图并重建邻接矩阵。公开 `run_training.py` 的 `DDPM` 则：

- `mol_to_graph` 构造七列原子特征；`compute_loss` 对 `data.x` 加噪，按原子采样时间步，最终计算原子特征重建 MSE（82–93 行及随后特征构造）。
- `reverse_diffusion` 调用编码器时只传原始 SMILES 列表，没有把 `x_t` 或 `t` 输入编码器或 MLP（70–79 行）。
- 单分子图向量经 MLP 后截取前七列，重建计算中广播至各个原子；这不是逐原子对的邻接矩阵预测头。
- 正向使用累计 `alpha_bars[t]`，逆向式使用单步 `1-betas[t]`，二者系数也不一致。
- 原始调用多传一个 `False`，与 `model.py:133` 的函数签名不一致。上述张量行为指修正这一接口错误后沿代码逻辑得到的行为；原样代码本身还有运行障碍。

因此，当前公开分支不能直接作为论文邻接扩散公式的实现依据。损失仍可能提供图统计学习信号，不能据此说“完全没有学习”；也不能仅凭当前代码推断发布权重的训练过程。此前利用作者权重获得接近论文的下游指标，与从头复现其预训练机制是两个不同结论。

### 1.2 两尺度目标与视图构造

论文描述扩散预热、两尺度训练以及权重遮蔽视图。公开 `run_training.py:529–556` 每个 minibatch 先执行扩散更新，然后在分子损失与基序损失之间交替更新；没有在同一批次显式计算 `L_graph + α L_motif`。两种视图使用相同模型、不同深度（depth 与 depth−1）和 dropout。

`cmpn.py` 导入了 `prune`，但本次检查的文件没有实际调用权重剪枝。可见视图主要来自激活 dropout 和深度改变。`loss.py:34–58` 的 PointwiseLoss 对 batch 维标准化，构造交叉相关矩阵并惩罚对角偏离与非对角相关。因此，提出动态 α 前需要先确定研究对象：论文中的联合目标，还是公开代码中的交替更新。

### 1.3 基序表示不是简单地截取分子末层再平均

`cmpn.py:105–156` 对每个基序实例重新进行一套区域相关消息传递。其输入保留对应原子的入边，边界邻居的信息可能进入，所以也不能直接称为严格隔离的诱导子图。

实例内 mean pooling 后，代码又对 minibatch 中同一种官能团的全部实例求均值，最终输出以基序类型为单位的向量。实例身份与数量没有通过这一步显式保留。代码还把 padding 原子索引 0 放进实例的平均计算；它对表示尺度和数值的影响需要另做验证。

mean pooling 不保证保留全部结构信息，但前面的消息传递已经编码部分结构，不能由“用了 mean”直接推出“没有内部拓扑信息”。区域 GNN 的研究应针对实际不可区分的结构、连接位置或边界信息，而不是只替换一个池化算子。

### 1.4 MotiL 与你的模型，感受野判断不同

MotiL 分子分支在局部消息传递后调用 `BatchGRU`（`cmpn.py:91`）；该模块用整分子的原子向量最大值初始化隐状态，再按原子序列运行双向 GRU（161–192 行）。因而后续原子表示可能依赖全分子，不能用局部 GNN 层数界定整个分支的依赖范围。其全局信息经原子顺序传播，是否对原子重编号敏感需要实验，静态代码不能量化实际敏感性。

你的 `diffusion_encoder/model.py` 虽然创建所有原子对张量，但 `pair_valid` 最终限制为有效节点、非自身且 `0 < bonds < MASK_BOND` 的化学键。因此它是局部键上传播，四层节点表示的消息依赖范围受四跳限制（输入特征自身携带的信息除外）。图级 Sum/Mean 能汇总全分子，却不等于显式建模任意远端节点之间的相互作用；也不能据此断言所有远端相关性质都无法预测。

## 2. 现有 H1/H4 结果应如何表述

依据：`results/lipo_h1_h4_simple_prediction_controls.md`。

在一个 Lipo scaffold split 和一个 H4-only 微调编码器上，冻结读出五个预测头初始化的平均 test RMSE 为：H1 0.82947、H4 0.68684、H1+H4 0.67415、H4+H4 0.68397。H1+H4 相比 H4 改善 0.01269，相比同宽度对照改善 0.00982。

这支持“在该固定编码器和划分中，浅层表示有可利用的增量信息”。不支持“五个独立数据种子证明泛化”，也不证明“H1 就是局部化学、H4 就是全局化学”。五个 seeds 仅改变预测头初始化，而且测试集已被多次查看，属于探索性结果。

现有 λ=0.5 和 λ=1.0 的 H1/H4 双监督编码器，联合读出分别为 0.73452、0.73684，均差于原方案。因此当前证据不支持优先继续加浅层性质监督。后续若开展新实验，应预先确定方案与验证集选择规则，用新划分或新任务确认结果。

## 3. 相关工作与创新边界

以下为定向原始文献检索，不是穷尽性新颖性证明。

| 工作 | 与提案重合之处 | 对研究定位的影响 |
| --- | --- | --- |

| [MGSSL，2021](https://arxiv.org/abs/2110.00987) | 基序生成任务与多层次分子自监督 | “基序预训练＋多尺度目标”已有明确先例 |

| [FragNet](https://arxiv.org/abs/2410.12156) | 原子、键、片段及片段连接四层解释 | 不能只宣称首次关注片段连接；其非标准键连接场景也值得区分 |
| [GraphGPS，2022](https://arxiv.org/abs/2205.12454) | 局部消息传递、全局注意力及位置/结构编码结合 | 局部＋全局组合本身不足以形成独立贡献 |

| [HimNet，2026-02-14](https://www.nature.com/articles/s42004-026-01922-x) | 原子、基序、图级层次及跨层注意力交互 | “区域相互作用＋保留原子通道”的宽泛设计已高度重合 |

上述重合不表示你的方案一定没有价值，而是贡献必须落在可明确检验的差异上，例如连接端点、跨区域键及边界上下文如何保留，以及这些信息是否真正改变拓扑区分能力。注意力图本身不能证明真实物理相互作用。

## 4. 六个方向的修正与优先级

1. **多层读出：作为必要诊断与基线。** 检验 H1–H4 的增量信息，控制输入宽度、头参数量与划分。它能帮助确定信息瓶颈，单独方法新颖性弱。
2. **区域内部结构：更聚焦边界与连接位置。** 先找现有表示不能区分的结构对，再设计保留内部边、连接原子身份和跨区域键的编码。区域 GNN＋Mean/Max/Size 本身不是新方法。
3. **长程区域交互：针对你的局部编码器提出。** 需要与更深局部模型、全局注意力和现有层级方法比较，匹配参数或计算预算。不能以 MotiL “只有有限跳”作为前提。
4. **任务自适应区域：保留为后续问题。** 固定区域重加权与重新学习区域划分不同；后者需要明确覆盖、重叠、连接与可解释性约束，并检索更针对性的任务条件池化工作。目前检索不足以确认该方向新颖性。
5. **动态损失权重：先澄清目标实现。** 可以是训练优化对照，暂不宜作为主要方法贡献。
6. **预训练学到了什么：当前最值得先做的研究设计。** 区分输入已有信息、局部拓扑、边界连接及远端依赖；以问题驱动后续结构修改。

建议研究问题改写为：**在固定原子编码器下，保留区域连接端点与边界结构，是否比普通区域池化更有效地补充性质预测所需的结构信息？其收益是否来自真实连接信息，而非参数增加、分子大小或基序组成？** 这是待检验的问题，不是已经成立的创新结论。

## 5. 后续实验设计草案（未执行）

- 探针先比较原始输入与各层表示。元素、度数、芳香性等已经是你的输入字段，预测这些标签不能单独证明学习了新知识。
- 结构任务可包括区域内部连接、连接端点和节点对最短路。节点对任务需要控制图大小与端点特征；线性探针失败不等于信息不存在，可与小 MLP 对照。
- 通过原子重编号、连接端点替换或保持基序组成的连接改变，检查表示的依赖与区分能力。化学结构变更应保持有效性；预测差异不自动等同于真实物理因果效应。
- 下游最低对照：原 H4、H1+H4、同宽度重复表示、普通区域池化、保留边界/连接的区域编码、加入区域传播，以及匹配预算的原子模型。按固定验证规则选模型。
- 若最终宣称长程收益，必须按结构距离分层，并在合适任务上展示；大图上效果提高本身不足以证明长程机制。若宣称普适改善，则需独立编码器种子与新的 scaffold 划分或任务。
