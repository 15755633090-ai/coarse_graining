# HMG 三尺度设计控制 v3（2026-10-26）

正式训练继续暂停。旧 19/21 结果保持原样，不能与修订协议合并统计。当前检查是代码验证，不是新的性能证据。

## 实现的控制

| 问题 | 对照与代码行为 |
|---|---|
| 跨尺度交互和辅助损失混入单尺度结论 | native 保留作者传播、跨注意力、尺度注意力权重及残差；noaux 仅从目标函数移除对齐损失。isolated 使用独立计算路径，只实例化参与预测的编码器，没有跨尺度注意力和对齐损失；这是项目新增模型。 |
| 注册参数量不等于有效容量 | 保存预测损失及总损失连接到的参数数量和名称；common-head、common-head-noaux、isolated 使用同族两层 MLP，单尺度加宽匹配对应组合的目标函数连接参数量，误差不超过 1%。该计数不等于表达能力相同。 |
| 单尺度仍经历原融合残差和激活 | single-direct 与 single-direct-noaux 将原分支表示直接送入预测层；与保留原单分支融合的模型配对比较。此对照不等于独立信息源实验。 |
| 标签标准化改变 MSE/辅助损失比例 | 所有目标函数均在原标签单位计算 MSE，然后加 alpha×对齐损失。若显式选择标准化输出，使用训练集统计量，反变换后再算 MSE；变换最后一层以保持初始物理单位预测。优化过程仍可能不同。 |
| 预算不足和测试集选模 | 仅按验证 RMSE 选模；预先声明递增预算，同一比较面板统一延长上限，保留相同 patience=50；预算受限必须显式标记。训练器不访问测试集，封存工具拒绝缺组、不配对、提前测试和检查点变更。 |

## 实验入口与验证

`python -m motif.train_hmg_design` 默认只做 smoke。正式阶段必须显式提供准备数据、输出目录、study、训练上限、预算阶梯、标签处理和调度器。baseline 先训练同 study 的 ASD；fusion 复用其 ASD，不重复挑选完整模型；controls 对各组合的组成单尺度进行容量匹配。single-direct 对照使用 native 基线，关闭辅助损失的对应版本使用 noaux 基线。

`python -m motif.check_hmg_design` 使用训练数据小样本检查原 ASD 前向严格一致、隔离路径不受其他输入干预、有限梯度、实际容量匹配和输出反变换。

`python -m motif.seal_hmg_design --plan PLAN --runs RUN... --output SEAL` 验证完整配对面板，重新核对验证历史，封存所选检查点、协议与来源目录。

`python -m motif.evaluate_hmg_sealed --seal SEAL --prepared PREPARED --output OUTPUT` 在全部代码、原作者源码、特征缓存、准备数据、检查点和封存哈希验证成功后才允许测试前向；只评估已选检查点，不训练、不选模，不覆盖既有评估目录。尚未执行正式测试。14 个 smoke 检查点的加载路径使用验证集精确重放检验，不能代替完整正式评估验证。

`python -m motif.check_hmg_sealing` 使用合成验证历史测试封存闸门，不读取分子测试数据；`python -m motif.check_hmg_evaluation_restore` 使用既有 smoke 的验证集检验测试入口的模型恢复代码。两者均不恢复正式训练。

2026-10-27 补充验证：`python -m motif.check_hmg_resume_capacity` 在同一批 4 个训练分子上检查全部 27 个容量匹配对照，最大有效参数量相对误差为 0.01465%，小于 1% 门限。最大预测头宽度为 5469，说明容量对照的头可能显著加宽；这只是参数预算控制，不代表等价表达能力或相同优化难度。native、noaux、common-head-noaux、single-direct、single-direct-noaux、isolated 共 6 类 A 模型完成两次更新的 epoch 边界保存恢复检查，继续更新后的损失、所有模型状态和 Adam 状态均精确一致。结果保存在 `runs/hmg_design_v3_resume_capacity_20261027/acceptance.json`。此检查不覆盖任意 batch 中断的恢复，也不证明完整训练性能稳定。

验证历史现在必须从 epoch=1 连续记录，且不能超过声明上限；缺轮次、重复轮次或回退预算会被拒绝。封存的合成历史检查扩展到 11 项。旧实验仍保持 19/21 暂停状态。

逻辑清单 `runs/hmg_design_v3_plan_20261026.json` 有 5 个种子共 340 个控制配置，只生成清单，没有启动训练。可在训练前依据配置完全相同与参数匹配结果去重，不允许依据性能去重。此完整诊断矩阵应分阶段运行，主问题仍是 native 七组，其他对照用于定位差异原因。

## 论文对应边界

alpha=.15、回归 tau=.30、Adam 初始 lr=.001、batch=64、patience=50 与已审查材料对齐。原作者回归代码、精确 scaffold 行号、完整学习率日程、标签缩放和最大训练轮数仍缺少公开确认。新 scaffold 分组与训练集描述符标准化已明确标记为本地实现，不能保证逐数值复现论文。

isolated 的 S 去掉原整体统计 token，改用可训练 CLS，保留 motif token 编码；D 只保留描述符 MLP；A 复用原原子传播及读出。它们隔离计算路径，原始 motif 和描述符仍可能编码共同的化学信息，不能称为三个互斥信息源。任何组合表现弱于子组合，只支持当前协议下没有额外预测收益，不能直接证明信息冗余。
