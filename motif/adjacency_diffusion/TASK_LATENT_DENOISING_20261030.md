# 回到基序原设计：任务对齐的隐状态条件去噪

本候选保留原能达到ESOL验证RMSE0.787109的原子分辨率BRICS双状态主干、全部原子/键特征、边界门控和均值读出。**不添加神经模块，不增加参数，不改推理干净路径。** SVR仅作为外部性能参照，不进入本模型。

## 需要修正的计算链

此前主要检验了受损化学边恢复预训练，再将编码器迁移给干净性质预测；这些结果不能直接否定最早“基序自身信息→上下文条件增强→性质预测”的目标。新候选只改变训练任务：上下文模块处理受损的基序隐状态，其输出既承担性质监督，也恢复干净的、受到性质监督的上下文表示。

[Noisy Nodes，ICLR2022](https://arxiv.org/abs/2106.07971)支持研究将去噪与主任务联合训练，而不只依赖预训练迁移。[GraphMAE2](https://arxiv.org/abs/2304.04779)研究过潜在表示恢复作为图学习监督。这些文献只提供动机；本候选不是两篇论文的复现，也不照搬其3D目标、EMA教师或解码器，更不保证带来收益。

## 与原设计逐项对应

| 原设计要求 | 本候选 |
|---|---|
| 基序先有内部结构状态 | 首层s仅在同BRICS片段内沿结构关系更新，形成s1后才进入上下文更新 |
| 保持原子分辨率 | 每个原子保留状态；不构造基序节点、不整片段池化 |
| 根据连接方式学习环境 | 保留原关系消息、真实连接与全部键特征、跨边界软门控 |
| 只破坏基序隐表示 | 按整片段选择所有所属原子，扰动隐藏状态，不扰动原子属性、化学键或坐标 |
| 增强结果参与性质预测 | 受损分支最终fuse输出直接进入原性质头，不另设可绕过的去噪头 |
| 一次干净推理 | 原MaskedBondModel.forward逐位保持不变，同一上下文增强器参与干净预测 |

内部独立性以传播范围为界。输入仍含度数、氢数等完整原子属性，因此这是给定边界条件的内部结构状态，不宣称完全环境无关。

## 噪声和信息边界

只有多基序分子参与片段扰动。每图随机选择ceil(0.3K)个片段，至少1个、最多K-1个，留下上下文；单片段分子保持干净并照常接受性质监督。噪声强度从0.1、0.3、0.5随机采样，这是一套事先固定的首轮设置，不是噪声网格搜索。

选中片段的首层内部状态s1、首层门控仍会读取的s0，以及并行上下文初态h0都同步处理：

\[ \widetilde q=q+\sigma\operatorname{sg}(\operatorname{RMS}(q))\epsilon+\Delta e_\theta(\sigma). \]

RMS按原子隐藏通道计算，带1e-4下限；高斯噪声独立。噪声层级标记复用原时间MLP，使用相对干净状态的嵌入增量，不增加参数。必须重算门控输入，避免干净s0/h0绕过受损s1。未选中原子的隐状态保持原路径。后续内部状态仍只在片段内部传播，上下文状态允许跨片段交换。

本式是隐状态加性高斯去噪正则化，不是DDPM生成器；不声称实现了反向扩散采样。完整真实图和键属性是已知条件，本任务不恢复缺失化学结构。保留目标残留信息，不声称强迫模型使用上下文，也不声称严格缺失基序推断。

## 任务对齐目标

设z是同一模型干净分支最终的原子fuse状态，z̃是受损分支经过相同上下文更新后的fuse状态。两者都直接接原性质头：

\[L_{task}=\tfrac12\bigl(\ell(H(\operatorname{Pool}z),y)+\ell(H(\operatorname{Pool}\widetilde z),y)\bigr).\]

没有多基序可扰动的分子，第二项直接复用第一项的预测，保留其监督权重，不额外改变单片段样本的dropout视图。恢复监督只计算被选原子，先按图平均再平均有目标的图：

\[L_{latent}=\operatorname{Mean}_{G:|S_G|>0}\operatorname{Mean}_{v\in S_G}\operatorname{Mean}_{d}\bigl[\operatorname{LN}(\widetilde z_v)-\operatorname{sg}(\operatorname{LN}(z_v))\bigr]^2.\]

总损失为Ltask+0.1Llatent。干净目标由性质监督持续训练，不是额外随机教师；停止梯度仅控制该辅助项的梯度流，不能单独保证无坍塌。归一化只用于辅助目标，不修改性质读出。推理运行干净上下文增强，不能把t=0称为执行了缺失恢复。

## 有限、可否定的试跑

保持原模型参数、初始化、数据、60轮、Adam0.001、batch16、dropout0.1、无weight decay、clip5。初始化编码器与性质头哈希必须与原参考逐种子一致，原干净预测和参数量已测试逐位相同。

首轮仅任务种子0的两个完整运行：A只做受损分支性质监督，辅助权重0；B完全相同但辅助权重0.1。两者同样两次编码器前向，噪声/片段/层级独立RNG流配对。B只有比A和原种子0参考0.814977都低至少0.01时，才触发事先固定的种子1/2复核。否则停止这套配方，不追加局部噪声、权重或正则搜索。

这个门槛是预算决策，不是显著性检验。触发时，种子0已经参与选择，不能把三种子均值写成无选择偏差的确认；种子1/2应单列。还需对照原三种子0.787109以及SVR0.772921，不能只超过较弱的新对照便称突破。两分支比原单分支计算更多，原参考不是严格算力匹配。

这两个运行的决策价值是区分“任务监督的隐状态噪声增强”与“额外显式表示恢复”的作用，不给每个部件启动消融。没有性能信号前，不追加上下文扰乱实验。

这是一轮探索性单种子负结果，不是显著性检验，也不能证明所有条件去噪方法都无效。它直接否定了“这套联合隐状态恢复设置已经带来改善”的说法。较低训练误差与较差验证误差相伴，只能说明当前辅助约束未改善迁移/泛化；不能据此确定过拟合是唯一根因，也不能判断边界门控冗余。恢复目标偏离性质所需表示、过强的不变性或优化干扰仍是未区分的解释，当前不为这些解释自动开新实验。

本候选保持了内部结构、基序关系、边界上下文与原子分辨率。它仍采用一次干净推理，**并未实现推理时先显式恢复再预测**。若将后者作为必需设计，下一候选必须明确恢复输入、输出及其进入预测的路径；不能拿本轮结果宣称该路线已被验证或否定。后续方法选择应同时满足原设计和下游收益，不以恢复损失下降替代性能证据。
