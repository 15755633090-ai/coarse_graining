# 整体方法审视：先明确实验能改变什么判断

## 本轮工作方式的问题

本轮将观察到的局部差异依次转化成了调参或结构候选，但没有事先建立足够清晰的整体假设与决策分支。失败结果主要筛掉了配置，并没有相应提高对根因的判断力。不能把25组性质训练、7组预训练的数量当作已经充分研究了方法。停止新增训练；以下审视优先于继续搜索。

## 当前真正检验的计算路径

预训练：干净原子条件＋干净BRICS归属＋受损/遮蔽化学边 → 内部/上下文原子状态 → 节点对解码 → 恢复17维化学边。

下游：完整干净分子＋BRICS归属 → 同一编码器的干净原子状态 → 分子读出 → 性质监督。

两阶段主要通过编码器参数联系。下游没有直接读取恢复出的边，也没有直接读取“去噪后的基序向量”。因此，当前研究对象是化学边恢复预训练的迁移价值。这符合后来原子级预训练路线的一种实现，但不能作为对最早“先得到更好的基序表示，再用其预测”设想的直接验证或否定。

内部状态确实沿片段内部传播，能够学习片段内结构；但当前没有显式的整片段汇聚/广播表示。BRICS归属主要用于组织传播。不能据此说模型没有基序信息，也不能认为已经保证了“先建立独立的整体基序自身表示，再引入环境”。内部特征还保留边界条件，不能声称完全环境无关。

整体需要回答的是：恢复任务鼓励的局部边信息，是否形成了干净预测路径可用、且分子读出能利用的表示？当前证据没有把这条信息链闭合。任务不一致、优化/遗忘、数据覆盖或读出受限仍是待区分的假设，不能任选一个当成根因。

## 已有实验能与不能支持什么

| 证据 | 可以得出的判断 | 不能得出的判断 |
|---|---|---|
| 输入、遮蔽、梯度、对齐和恢复公式测试 | 被检查的计算路径符合接口约定；目标自身残留被移除 | 表示有迁移价值、上下文或门控有效 |
| 同架构scratch/unmasked/masked | 当前512分子/1200更新、ESOL验证设置下，预训练没有稳定增益 | 预训练一般无效，或已经定位退化原因 |
| 低学习率/强正则 | 这些具体成组设置没有改善绝对最佳结果 | 过拟合是唯一原因；超过被削弱的scratch就算成功 |
| 按观测质量归一化、后验权重 | 可以排除这些修补作为当前设置下的稳定解法 | 归一化/概率校准一般无用，原启发式权重本身就是代码错误 |
| 限定t≤300 | 在目标保持完全遮蔽时，这个具体范围仍未稳定改善迁移 | 高噪声不重要；恢复更好或更差就决定下游好坏 |
| 表示尺度诊断、新读出、重置fuse | 尺度差异存在；两个具体适配方案没有解决迁移 | 尺度是根因或完全无关；恢复任务学到的全部信息都无用 |

最有帮助的已有结论是：流程可运行；当前协议存在负迁移；单点修补不能稳健补救。多数其他结果只能筛掉配置，不能定位整体问题。所有消融必须对照最强可比基线，不能只对照被新设置削弱的模型。

## 重新安排判断顺序

1. 先用方法说明和计算图固定目标表示、输入条件与性质分支实际使用的量。若目标是基序自身结构加环境作用，应明确整片段表示在哪里形成，以及它怎样进入预测；不能只用恢复损失代替定义。
2. 当前原子级预训练路线最缺的证据，是干净编码器表示对性质任务的可用性，而不是更多恢复率曲线。待信息链确定后，一个固定容量、相同训练规则的冻结表示探针，才有明确决策价值：若预训练在探针下更好而全参数微调更差，优先研究迁移/遗忘；若探针也不支持改善，则先审视任务目标、信息组织与语料覆盖。探针只评价选定读出族的可用性，不能证明表示包含或不包含所有性质信息。本轮尚未运行当前18通道版本的这项对照，不能挪用早期17通道结果。
3. 固定目标遮蔽后干预上下文，只能回答恢复是否使用上下文；它应服务于机制主张，不能代替性质迁移证据。当前主要问题是下游收益，不应把它当成优先的全面救援实验。
4. 每个后续实验先写：竞争假设、唯一主要干预、结果分支将改变什么设计决定。若两种结果都只会导致“再调一点”，就不启动。对失败配置不再追加无尽的邻近参数搜索。

当前最可靠的可用参照仍是原mean-readout从头组，验证RMSE0.78711。其余结果均保留；没有评估测试集，也没有把当前负迁移解释为对最初基序研究目标的否定。
