# 固定化学目标预训练：单一候选配方

## 动机与文献边界

已有30检查点核验表明：边恢复组能够更好拟合训练标签，却没有更好的最佳验证结果；后期过拟合存在，但不是唯一解释。此前更换损失为全图视图一致性后，预训练图读出有效秩接近1，仍未提升性质预测。现有证据不支持继续仅调整恢复难度或重复正则搜索。

[Does GNN Pretraining Help Molecular Representation? (NeurIPS 2022)](https://papers.neurips.cc/paper_files/paper/2022/file/4ec360efb3f52643ac43fda570ec0118-Paper-Conference.pdf) 系统比较了预训练、输入特征、划分与架构，指出自监督预训练并非总能优于充分配置的从头模型。其结果不能直接替代本项目的回归实验。

[KPGT (Nature Communications 2023)](https://pmc.ncbi.nlm.nih.gov/articles/PMC10663446/) 使用计算描述符和RDKit指纹作为化学知识，支持研究有固定化学含义的目标。原方法有知识节点、200维描述符、512位指纹及更大的架构和语料；本候选只借鉴计算目标的思想，**不是KPGT复现，也不是新的扩散公式**。

## 改变什么

预训练输入干净图，原BRICS双状态主干、软门控、原子特征、全部键属性与均值读出保持不变。用性质分支同一个64维图读出，经一个线性辅助头预测12个计算描述符和512位RDKFingerprint；没有知识节点、教师、自举目标或额外输入描述符。

描述符：MolWt、MolLogP、TPSA、HDonors、HAcceptors、RotatableBonds、AromaticRings、AliphaticRings、FractionCSP3、RingCount、HeavyAtomCount、ValenceElectrons。它们是先验化学知识，包含与溶解度相关的计算MolLogP，必须披露；不是实验标签，也不是真实ESOL标签的替代值。

只用4096预训练分子拟合各描述符的均值/标准差，屏蔽常数目标。指纹仅保留训练语料中可变位，训练语料频率决定正类权重，上限20。损失为可变描述符均方误差与可变指纹位BCE之和；两块分别平均后相加，不搜索权重。

这联合改变了上游输入和监督目标：**不把不同分子的结构差异要求为不变，也不要求一个随机编码器提供优质教师**。固定目标避免自举目标共同变为常数的解，但不能保证中间表示满秩或性质相关；必须实测。没有继续叠加旧恢复损失，避免无法判断新配方的实际价值。

## 固定预算与验收

- 同一4096分子语料，继承此前ESOL规范SMILES排除；不按验证标签筛选分子。
- 上游种子7/1/2，各1200次更新、batch8、Adam0.001、clip5、dropout0；图抽样RNG与此前扩展语料实验一致。
- 每个上游图只跑一次编码器；新辅助头与旧边解码头的计算不同，因此相同更新数不等于严格相同算力。记录实际耗时；不以弱化算力对照作显著优势论断。
- 最终上游步骤用于迁移，不根据确认集目标误差选模型。128分子确认集仅诊断固定目标预测和有效秩。
- 迁移只有原编码器；辅助头丢弃。下游仍用原MaskedBondModel、原均值读出和与从头组逐种子一致的新性质头。
- 下游原ESOL scaffold train902/valid113、目标缩放仅训练集拟合、batch16、Adam0.001、dropout0.1、无weight decay、clip5，完整60轮，各自按验证选择最佳；三种子全部保留。
- 首要比较原最佳从头0.78711和同语料原边目标0.84288，不能只对更弱的改动版本宣称胜出。无论正负，当前复用验证集、三种子都不足以证明普适收益。
- 两项接口测试核对目标的SMILES顺序一致性、标准化/常数维掩码、有限梯度、与性质分支完全相同的读出、辅助梯度到编码器且不进入旧头。源码及哈希在运行前冻结。

脚本：`_github_sync/run_chemical_anchor_20261030.py`。输出：`runs/chemical_anchor_20261030/`。上游保存最终模型、辅助头、统计量、优化器与抽样RNG；当前脚本没有自动上游断点续跑接口，不声称支持恢复。下游沿用已验收保存协议。

## 决策含义

如果固定化学目标在确认分子上优于训练语料常量预测、保留更丰富图读出，并改善下游，说明这条具体配方值得独立任务复核；仍不能将收益分解成干净输入、描述符、指纹三者之一。若目标预测有效而下游仍无收益，则这套化学目标在当前小规模语料及任务下也不足，不能继续把恢复指标当作性能代理。完成固定三种子后，不自动搜索附近超参数。

## 完成第一阶段及针对性领域修正

4096 ZINC化学目标组已完成：三种子RMSE为0.815820、0.785196、0.759233，均值0.786750、样本标准差0.028325。原从头均值0.787109；平均差仅-0.000360，1/3种子优于各自从头。不能称为稳定提升。它在本次配对比较中优于4096边恢复组，但目标和输入同时改变，不能拆分归因。

源领域确认集上，描述符标准化MSE为0.07132/0.05377/0.07167；对应图读出有效秩5.66/5.75/5.39。原自举图目标的近一维现象没有在这些测量中重现，但这不是整个表示的满秩保证。确认集指纹宏AP约0.851，对应宏阳性率约0.733（非空阳性位上）；不能把AP当作精确分子恢复率。

**更重要的迁移诊断：** 不使用性质标签，直接让该固定化学目标头预测902个ESOL训练分子的描述符，相同的上游标准化尺度下，平均MSE升到2.20300/1.91837/2.27690。MolLogP本身也从源确认集0.06443/0.05712/0.09677升到ESOL训练结构0.55246/0.66230/0.51981。两批结构的分布和难度不同，因此不能凭MSE比值确定下游根因，但它直接证明了“源领域目标学会”不能替代“当前领域目标预测有效”。

补充的事后固定描述符Ridge基线（StandardScaler仅训练拟合、alpha=1、无搜索）得到训练RMSE0.8904、验证1.3523，也没有超过图模型。它仅排除了这套固定线性配方作为现成改进；不能否定描述符的非线性价值。

依据以上新证据，开展一次固定的**领域内自预训练**：同一化学目标、原主干、1200更新和全部3种子，仅将上游语料改为902个ESOL训练分子的结构，描述符统计也仅在该语料拟合。没有上游性质标签、没有验证/测试结构或标签。这与全部ESOL结构都排除的通用ZINC预训练协议不同，必须独立命名，不能宣称获得了额外分子数据优势。

这不是附近学习率/权重搜索。其可否定预测是：领域内计算目标更准确，并在原监督微调预算下得到更好的配对性质结果。若计算目标变准而性质仍无收益，就不能继续把领域对齐当作足够条件。比较不同语料下的描述符预测时，额外保留使用同一ZINC尺度的误差，避免标准化分母变化造成假改善。

领域内脚本为`_github_sync/run_in_domain_chemical_anchor_20261030.py`，输出`runs/in_domain_chemical_anchor_20261030/`。新阶段同样在训练前冻结源码/计划，三种子全部完成后判断，不依据单个种子追加调参。

规范SMILES复核：902条ESOL训练记录对应893个不同规范分子，领域内阶段保留原记录权重，没有去重。与验证、测试规范分子均无交集。902是样本记录数，不能写成902个独立不同分子。

**本轮对整体判断最有价值的结果：** 以同一ZINC描述符尺度衡量，领域内预热将ESOL训练结构的计算目标平均MSE从2.203/1.918/2.277降至0.142/0.145/0.108，但性质验证没有获得更好的均值。后者是目标领域训练结构上的拟合诊断，不是独立结构泛化指标。这否定了“只要当前领域化学目标预测变准，下游就会改善”的充分性假设；不能再用该辅助指标下降来验收性能改进。

因此，现有证据不支持将问题简化成恢复不够准、缺乏固定化学目标、或目标领域样本缺失中的任一个。任务相关信息如何在有限监督下有效使用仍未解决；本轮没有唯一定位根因，也未证明原门控模块无效。新的化学目标可作为代码中可复核的候选，但目前没有稳定额外收益。
