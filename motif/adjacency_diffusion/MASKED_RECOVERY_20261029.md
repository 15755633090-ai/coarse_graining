# 成组遮蔽：减少目标键残留信息

本次只修改去噪预训练任务，不提高性质监督强度、不调整门控/读出，也不宣称去噪恢复率越高越好。新增 `--variant masked`，使用原 frequency_init 的类别频率初始化和原四组化学键分类恢复目标。

## 具体输入与目标

1. 对所有有效候选原子对的17维化学边状态做原高斯加噪，时间步默认随机取1–1000。原子133维特征及可选BRICS归属继续作为条件。
2. 在不知道该原子对是否真实成键的情况下，以默认.3概率独立抽取上三角候选对，并镜像为对称遮蔽。只从候选对掩码和RNG抽样，不根据真实连接、类型或边界选择，避免“遮蔽位置就是答案”。
3. 对选中位置同时清除17个受损通道，包括有无键、类型、立体、共轭、环信息，并添加第18维“未知”标记。它不同于无键类别，不将未知位置伪装成确定无键。编码器与恢复头都只能接收该遮蔽后输入，不能沿恢复头跳接读取原受损向量。
4. 有候选对的分子若一次没有抽到遮蔽位置，随机补选一对，保证其恢复目标非空。因此小分子的实际遮蔽比例可能高于.3；单原子分子无候选对，产生可微零恢复损失，不产生伪造目标。
5. 默认仅在遮蔽位置计算恢复损失；其他位置仅提供受损上下文。类型损失包含无键类别，其他三组仍只在被遮蔽的目标真实键上监督，保留全部化学属性。

未知候选边的消息权重使用训练集总体成键率，不读取目标真值；其他可见位置沿用已有受损观测权重。原始完整边特征只用于构造目标和干净性质分支。BRICS、原子度数/H等来自干净分子，依旧是已披露的额外结构条件；因此不宣称完全隔离的缺失结构推断。

## 干净预测和兼容性

干净预测输入保留完整17维真实化学边特征，第18维标记恒0，一次前向输出性质，不执行随机遮蔽或采样。预测功能流程保持不变，但额外输入通道使边编码器/恢复头参数形状发生变化，所以不能把旧17通道检查点直接载入。新格式 `typed_gaussian_pair_mask_v1` 严格独立。

后续比较需用同一18通道架构的 `--pair-mask-ratio 0` 作为无成组遮蔽对照；它仍使用高斯去噪、在所有候选对上计算原目标。不能把旧17通道模型与新模型的差异全部归因于遮蔽。固定.3只是第一版设计值，尚未调优，尚未证明模型一定更多利用跨基序上下文。

## 运行

```powershell
python -m motif.adjacency_diffusion.typed_train --stage pretrain --variant masked --pair-mask-ratio 0.3 --smiles-csv TRAIN.csv --valid-csv VALID.csv --output-dir RUN/pretrain --motif-prior --conditional-gate --device cuda:0
python -m motif.adjacency_diffusion.typed_train --stage finetune --variant masked --pretrained RUN/pretrain/best.pt --output-dir RUN/finetune --dataset esol --motif-prior --conditional-gate --epochs 60 --patience 60 --device cuda:0
```

模型配置需与预训练一致，遮蔽比例默认从检查点继承。仍支持显式 `--training-max-t`，但本次默认采用全范围1000，未再按恢复率限定到300。建议性质比较统一实际60轮，以避免此前早停混淆。输出目录防覆盖，恢复支持模型/最佳快照/优化器/时间步与遮蔽RNG。

评估同时记录全部候选对指标和单独的 `masked_recovery`（分母、连接AP/精度/召回、真实键类型、四属性联合、按键类型和非默认立体分组）。总体指标可能主要反映可见位置，解释新任务时须优先查看遮蔽位置指标。空组保留null。

不同遮蔽比例对应不同恢复难度与目标位置，不能直接用各自恢复损失的高低挑选性质预训练策略。后续主要检验仍是同架构、同预算的性质预测，不预设恢复率下降会带来泛化收益。

## 验收与结论边界

33项测试通过，其中新增6项覆盖对称/无效位置、17通道全部清除、标签独立抽样、遮蔽位置残留梯度为零、仅遮蔽位置受监督、干净预测保留真实键特征、原子重排、孤立原子、检查点回放及遮蔽RNG中断恢复。latest提交后模拟中断，恢复权重与历史同连续训练逐值一致。

CPU小流程已完成预训练和ESOL微调，使用小样本/小隐藏维度/少轮数，仅验证执行与检查点回放。没有启动新的多种子性质实验，没有证明上下文依赖增强或性质泛化改善。任务变难可能降低恢复指标，这本身既不是成功也不是失败，最终仍须以同架构性质对照判断。

最终源码的小验收记录为 `runs/masked_bond_acceptance_20261029`：遮蔽版 train/valid 各16分子、hidden12/layers2、CPU、预训练两轮及ESOL微调两轮；同形状 ratio0 对照各8分子、预训练一轮。三条流程均完成最佳检查点回放；样本数不同，仅是接口验收，不作性能比较。
