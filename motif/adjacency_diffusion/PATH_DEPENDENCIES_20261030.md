# 用可控路径门控检查当前模型依赖

## 目的与决策

检验已有模型实际依赖哪些信息路径，筛选值得做重训移除对照的候选。新增的是固定系数的诊断开关，不是通过小权重自动宣称冗余的稀疏门控。原有逐边自适应门控保留。所有新开关默认1，权重、参数量、检查点格式和原默认预测行为不变。

固定权重关闭路径，回答的是“这组已训练参数是否依赖该路径”。它不回答“从头移除模块并重新训练，其他路径能否补偿”。测试把中间状态置零会引入分布变化，误差上升可能包含状态校准和共适应被打破的影响，不能直接解释为独有化学信息的贡献。

## 每个开关的精确定义

| 设置 | 干预 | 保留什么／能回答什么 |
|---|---|---|
| full | 所有系数1，原learned边界门控 | 回放历史验证分数 |
| no_internal_branch | 每层内部状态s在使用前及更新后置零 | 同时切断s到边界门控、上下文更新、最终融合的路径；h的片段内传播保留，不等同于移除全部BRICS机制 |
| no_context_within | 关闭h路径的同片段消息 | s路径保留，检查两套片段内处理是否可相互替代 |
| no_context_cross | 关闭h路径的跨片段消息 | 保留完整原子/键输入及全分子读出，不等同于删除全部环境信息 |
| no_internal_readout | 仅将最终fuse的s输入置零 | s仍影响h及边界门控，不能叫删除内部支路 |
| no_context_readout | 仅将最终fuse的h输入置零 | s不读取h，因此此设置截断上下文状态通往预测的输出路径 |
| uniform_boundary | 将原边界门控设为1 | 同时改变条件化权重和消息幅度，不能单独归因于“自适应性” |
| no_internal_and_context_within | 同时关闭独立内部支路和h的同片段传播 | 查看两条路径的联合作用；非线性干预不保证误差单调或可相加 |

关系掩码和原归一化分母保持不变，所有原始化学特征仍输入。新开关是临时上下文管理器：嵌套或异常后自动恢复。带非默认诊断开关的模型禁止导出为普通检查点，避免重载时遗失干预设置。若以后训练永久删减模型，需要独立、可序列化的模型配置。

## 固定评估协议

使用原18通道对照的scratch/masked各3种子最佳性质检查点。8种预定设置，总计48次验证前向；没有新预训练或微调，没有使用测试集。验证113分子，其中多片段50、单片段63。单片段上关闭跨片段消息必须逐值不变。基线回放误差容差1e-6；评估前后模型状态哈希不变，源码规范化UTF8哈希不变。

报告原单位RMSE变化、逐种子差值和预测RMS变化。低依赖筛选条件在评估前写入plan：三个种子的|ΔRMSE|均≤0.01且预测RMS变化均≤0.05。这只是当前ESOL上的描述性阈值，不是统计等效检验或允许删除的证明。由于跨片段信息只在部分样本存在，单独报告多片段结果。

## 完成结果

下表为多片段分子的三种子平均ΔRMSE。正数表示关闭/绕过后变差。

| 干预 | 从头组 | 遮蔽预训练组 |
|---|---:|---:|
| 关闭独立内部支路 | +1.3111 | +0.9835 |
| 关闭h的片段内消息 | +1.5013 | +0.9587 |
| 关闭跨片段消息 | +0.1440 | +0.0220 |
| 关闭内部状态直接读出 | +0.7229 | +0.2393 |
| 关闭上下文状态读出 | +0.6140 | +0.6442 |
| 边界门控改为1 | +0.0176 | +0.0771 |
| 同时关闭两套片段内路径 | +4.0128 | +1.0856 |

没有设置通过三种子低依赖筛选。因此，没有证据把某个主支路判为可直接删除的冗余模块，也不据此启动一批删减重训。

最有决策价值的观察是跨片段消息的模型依赖差异：从头组三种子ΔRMSE为+0.0763/+0.1429/+0.2128；预训练组为+0.0636/-0.00005/+0.00235。后者并非所有种子都不需要这条路径，最大预测RMS变化约0.190。只能说当前预训练组的跨片段消息干预敏感性较低且不一致；不能宣称它已学到更好上下文、已经退化了上下文能力或这就是负迁移的因果来源。完整图读出即使在无跨片段消息时仍可聚合所有原子。

内部与上下文状态都明显被使用，否定了“看到双状态就直接删一条”的当前操作依据。边界门控改为1也会变差，当前没有将门控判为无用的证据。联合作用非单调，不能靠干预分数相加判断独立贡献。

下一步若验证真正冗余，必须指定一个候选，并比较保留／移除后同预算重训；当前结果尚未提供清晰的删除候选。若研究的是负迁移，应优先把上述跨片段消息依赖差异与干净表示的任务可用性联系起来，而非继续搜索噪声强度。
