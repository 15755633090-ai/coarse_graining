# 基序上下文去噪：失败定位与可迁移改进

检索与本地核验日期：2026-10-30。本文对应e2c63bc之后的分析，不改写历史结果。新增工作只有已保存检查点的只读诊断，没有优化器更新、候选训练或测试集评估。研究主线仍是原子分辨率下的内部基序结构、真实连接位点、边界上下文与隐状态条件去噪；保留完整原子和键特征。

## 1. 本次找到的具体证据

已重新读取task_latent_denoising.py、训练脚本、原主干与三组最佳检查点。使用同一902训练分子与113验证分子，重新计算干净预测；分组按BRICS片段数，与标签无关。两组新模型的整体验证误差与原完成记录在1e-6内一致。

重要修正：不能将整体均值解释成“去噪在所有样本都不起作用”。相对同样扰动的对照，恢复项在多片段组降低误差，却在单片段组明显恶化；相对最强原参考，多片段组只回到接近原水平，单片段组是主要退化来源。只有一组种子和一个反复使用的验证划分，样本数也小，分组观察不能当作机制的因果证明。

训练中只有438/902个分子有多个BRICS片段并参与扰动/恢复；464个单片段分子不参与。这不意味着它们不受辅助任务影响：编码器、融合和预测参数仍全部共享。辅助训练可以改变它们的干净表示。BRICS单片段也不等于没有化学上下文，只表示该规则没有产生跨片段边。

### 只读梯度与随机目标诊断

在前128个训练分子组成的8个固定批次上，检查已选最佳检查点；不以诊断结果选择新模型。梯度只比较共享编码器参数。

| 指标 | 扰动模型 | 恢复模型 |
|---|---:|---:|
| 辅助梯度与双分支性质梯度的平均余弦 | -0.03951 | -0.02093 |
| 余弦为负的批次数 | 4/8 | 4/8 |
| 0.1×辅助梯度范数／性质梯度范数 | 0.0860 | 0.0466 |

| eval模式下仅隐状态扰动的状态差异 | 0.009013 | 0.005608 |
| eval模式、零扰动的状态差异 | 0 | 0 |

这些结果支持：恢复约束没有持续与性质梯度同向；目标差异中包含dropout造成的视图差异。它们不支持：辅助梯度压倒主任务、梯度冲突已被证明是根因、或dropout一定应该删除。不同模式误差不可相加，不能把它们换算成“多少比例是假去噪”；两个模型的坐标空间也不同，不能把它们的MSE差直接解释成化学恢复率提升。端点梯度不能替代训练全程记录。

## 2. 整体问题的排序

**优先级一：任务作用范围与参数共享范围不一致。** 去噪仅作用于多片段样本，却通过全共享网络改变所有样本；目前分组结果与这种风险相符。这比继续调终点噪声或追求更高恢复率更直接。它仍是得到证据支持的解释，不是已确证根因。

**优先级二：当前目标其实是最终状态一致性，不是明确定义的基序恢复。** 输入在首层内部状态、并行门控状态和上下文初态三个位置受独立噪声；目标却是另一遍前向的最终fuse状态。优化要求“受损传播之后的最终状态接近干净最终状态”。这可以成为合理正则，但不能等同于“恢复加噪前的基序自身表示”。最终性质表示中的每个通道都被对齐，也没有规定哪些信息值得为性质保留。

**优先级三：随机且移动的恢复目标。** clean分支处于train模式，stop-gradient并不关闭dropout，也不固定跨更新的教师。随机视图一致性本身并非错误；如果研究主张是条件恢复，就需要区分人工噪声、dropout和目标漂移。直接加EMA也不自动提供优质目标或防止坍塌。

**优先级四：原设计与实际推理还有距离。** 当前推理严格调用原干净forward，未调用显式恢复模块。因此已测的是联合正则化；“预测前恢复后的基序是否更好”尚未被直接检验。在完整干净图上也没有天然的观测噪声可去除；仅恢复一个确定性编码器的干净向量，不能凭空新增分子信息。收益必须来自上下文建模、表示组织或训练归纳偏置。

**不能混为一谈的问题。** 旧边恢复预训练只有512分子，是旧迁移实验的重要限制；最新联合试跑直接使用902个有标签分子，其失败不能继续归因于512分子的预训练不足。训练误差降低而验证变差符合泛化恶化，但尚不能把它归结为简单容量过大、过拟合或正则不够。原模型本身训练后期也有验证波动，不能只看最后一轮。

## 3. 跨领域论文筛选：迁移原则，而非堆模块

以下以作者论文、会议全文或正式期刊正文为依据。方法机制与本项目的迁移推论分开；没有一篇论文能保证本模型改善。

| 文献 | 经核对的可迁移机制 | 对本问题的决定与边界 |
|---|---|---|
| [Side-Tuning，ECCV2020](https://arxiv.org/abs/1912.13503) | 固定已有网络，通过可训练的加性侧网络适配 | 当前最值得借鉴：保护已有效的内部结构与预测映射，新增环境修正，而非让恢复损失任意改写全部参数。不是要求换主干或加第二种模型 |
| [ControlNet，ICCV2023](https://arxiv.org/abs/2302.05543) | 冻结既有模型，使用零初始化连接接入条件分支 | 同一原则的生成领域证据：候选初态严格复现原模型。零初始化不保证训练后不退化；本项目没有必要复制整套图像架构 |
| [Ladder Networks，2015](https://arxiv.org/html/1507.02672v2) | 用受损低层状态和高层条件估计干净隐变量；侧向连接减轻高层重建细节的负担 | 区分“恢复内部状态”与“为任务形成上下文表示”；不要求最终任务向量每一维同时做重建。原论文不是分子实验，不能照搬BN/逐层解码器 |

| [Adapting Auxiliary Losses Using Gradient Similarity](https://arxiv.org/abs/1812.02224) | 根据辅助和主任务的梯度关系调整辅助贡献 | 可作为冲突诊断/备用，不优先直接加算法；当前只有端点接近正交的证据，没有“大梯度压倒主任务”的证据 |
| [PCGrad，NeurIPS2020](https://arxiv.org/abs/2001.06782) | 投影冲突的任务梯度 | 解决局部优化冲突，不保证验证泛化，也不会使无关恢复目标变得有用 |
| [ForkMerge，NeurIPS2023](https://arxiv.org/html/2301.12618v3) | 区分优化冲突与泛化；借助目标验证误差选择/合并辅助更新 | 很适合作为本轮判断依据：负余弦不等于负迁移。暂不迁移其验证驱动的多分支搜索，避免进一步消耗已反复使用的ESOL验证集 |
| [Graffe，2025作者稿](https://arxiv.org/html/2505.04956v1) | 图表示作为扩散解码器的条件，通过恢复学习信息 | 条件恢复应有明确的信息瓶颈；互信息/恢复充分性不等于性质充分性。原文主要节点/图分类，不能当作ESOL提升证据 |
| [DDT，2025作者稿](https://arxiv.org/html/2504.05741v2) | 分离条件表征编码与详细信号恢复 | 支持审视语义编码与恢复细节的职责。图像频率不是化学语义的现成对应，不直接移植Transformer或两套大网络 |

## 4. 推荐下一候选：受保护的基序上下文残差适配

只选择一套完整方案，不把上表算法全部组合。核心采用Side-Tuning式的参数隔离；零初始化只是确保初态可回退的实现约束。当前尚未实现或训练此候选。

1. 使用原同种子、只用训练标签得到的主干和性质头；固定其参数与eval行为。保留完整原子/键特征、BRICS结构、原子分辨率、内部/上下文状态及边界门控。禁止加载任何验证/测试标签训练的教师。
2. 定义确定性内部状态q_v（来自冻结内部路径、仅片段内部传播，含已披露边界原子属性）。它本身承载结构。只在辅助受损视图中，对选中整片段的q加噪；关系条件保留真实位点和键特征，不同时破坏多条平行状态。
3. 用一个小的关系感知上下文适配器接收q_t、相邻片段状态、位点关系与噪声层级，产生每原子的增强状态r。目标片段的干净q不能作为该受损视图的旁路输入。主干原干净输出可以保留为预测基底，但不能作为辅助恢复器的目标内容条件。
4. 辅助恢复使用r的投影预测选中原子的固定q；性质修正直接使用r。这样恢复和预测经过同一个上下文适配器，但不强制最终性质表示全部通道等于内部结构目标。投影头不是“性质不读取的去噪分支”：性质必须读取共享r；是否真正利用辅助任务要由无恢复的同架构对照判断。
5. 在原子表示层加入零初始化修正，再通过冻结的原性质头预测：z_v^+=z_v^0+I[K≥2]W_zero r_v。只训练适配器、投影与W_zero。单片段分子路由严格为零，因此无论辅助训练怎样更新，干净预测都保持原模型；多片段分子仍可能变好或变差。该路由只限制跨BRICS关系增强，不主张单片段没有化学环境。
6. 推理显式经过同一个适配器：使用干净q和干净状态条件，得到r并修正z；不注入随机噪声、不运行反向采样。必须训练这个干净路径，不能只训练高噪声再直接拿t=0使用。干净输入上的r称为上下文增强，不能声称它去除了不存在的观测噪声。

该方案与上一轮不同的实质是：固定已有好表示、将辅助更新限制在承担环境修正的参数内、恢复目标确定、增强输出显式进入预测。它不声称增加了输入信息；新参数和额外计算必须披露。冻结可能限制有用适配，这是代价；多片段只有438个训练样本，也可能不足。不能因单片段被保护而将总指标不退化当成去噪有效。

## 5. 什么实验值得做，结果改变什么决定

下一次若实施，先验收三个接口：零初始化时全样本逐位等于原模型；更新适配器后单片段仍逐位相等；性质梯度确实经过r，而受损恢复没有干净目标旁路。之后只比较固定参数和预算的两个候选：受保护上下文适配器（性质监督）；相同适配器加条件恢复。它们必须从相同原模型检查点启动，连同原模型作为不更新参照；若与全参数方法声称算力公平，还需计入原基底训练预算。

| 结果 | 决定 |
|---|---|
| 无恢复适配器已改善，而加恢复无额外收益 | 保留上下文机制；不把去噪当贡献，不继续搜辅助权重 |
| 加恢复稳定优于相同适配器及原模型 | 才进入上下文干预与独立任务复核，检查增益来源 |
| 两者都不能改善多片段组 | 停止本适配路线；转向内部状态/上下文表达能力，不继续磨恢复损失 |
| 只因单片段被保护而整体接近原模型 | 仅说明保护机制成立，不是性能突破 |

这个分组路由候选是在查看本次验证分组后提出的，属于事后设计，必须披露；不能将它在同一分组上的改善作为独立确认。单种子仅用于筛选，任何正结果需固定配方做配对多种子，并在独立任务上复核。不能用反复查看验证集的收益包装确认性结论，不评估测试集来选方法。若实验失败，下一路线应依据此表改变整体决定，不再围绕同一隐状态MSE继续邻近搜索。
