# MotiL 论文机制与实验对标规范（尚非新的实现）

更新：上述规范对应的独立邻接机制路径现已实现于 `motif/adjacency_diffusion`，详见其 README。本文保留当时对齐决策与旧属性试跑归档含义，不把旧结果追改为邻接结果。

来源：Molecular Motif Learning as a pretraining objective for molecular property prediction，DOI 10.1038/s41467-025-66685-w；正文 Methods / Diffusion priming，公式 1–5；Datasets / Training details。本地 paper_fulltext.xml 的 PMC 编号为 PMC12748552。论文页面：https://pmc.ncbi.nlm.nih.gov/articles/PMC12748552/ 。以下区分论文机制、已审计源码快照与本项目新实现，不把三者混称。

## 机制差异

| 项目 | 论文正文 | 当前 brics_atom_diffusion |
|---|---|---|
| 受损输入 | G_T=(A_T,X)，保留原子特征 | (A,X_t)，保留拓扑和键特征 |
| 加噪对象 | 邻接矩阵，含连接结构 | 原子属性 one-hot |
| 解码对象 | 噪声 → 一步还原邻接矩阵 A_hat | 节点噪声 → 一步还原 X_hat |
| 训练损失 | 公式 5 的 ||A-A_hat||² | 均匀 epsilon MSE |
| 时间机制 | 公式 3–5 明确写终点 T；更多采样细节需单独核对 | 每分子均匀采样 1..T |
| 编码器与特征 | CMPNN；原子八类属性、键四类属性 | 自建双状态 MPNN；原子三类 one-hot 与干净键条件 |
| 完整方法 | diffusion priming + bi-scaled training + task-specific fine-tuning | 单一属性去噪预训练 + 微调 |

因此，原子属性恢复准确率不能对标论文邻接恢复质量。损失也不是只更换参数化：同一前向日程下，干净数据误差等于 epsilon 误差乘 (1-alpha_bar_t)/alpha_bar_t。

已审计官方源码 2a8f006 的实际属性扰动/干净图编码/广播输出路径不等同于正文；这些结论仅针对该固定源码快照，不推出整篇论文或所有版本无效。当前新实现虽修正了输入与时间接口，也没有因此变成正文机制复现。

## 下一条论文机制对齐路径的必要边界

1. 保留 X，对 A 加高斯噪声，预测原子对噪声并一步还原 A，按 A 重建误差优化。若改用均匀 epsilon MSE或随机 t，必须另列方法修改，不能声称同一训练目标。
2. 去噪器的传播和解码必须真实依赖 A_t。不能保留原始真实 edge_index 或干净“有键/无键”条件作为候选边支持；只在真实键上预测无法检验恢复缺失连接，也直接透露答案。干净键类型通常也会暴露键是否存在，不能沿用当前属性去噪的完整干净键旁路。
3. 分子内候选原子对包含有键和无键，屏蔽 padding 与对角；无向对称性、是否仅计上三角、损失按分子/原子对归一化、连续 A_t 如何进入 GNN，均需在实现中明确。正文公式没有完整给出这些软件接口，不能把自行选择冒称已核验官方细节。
4. BRICS 源自 A_0，是新增结构条件。增强版若保留片段归属，应对所有候选对仅定义“同片段/跨片段”关系，不能把真实跨键端点集当作去噪候选支持或输入答案。即便如此，干净划分仍携带结构先验，必须披露，并让统一门控控制共享相同先验，区分先验增益与门控增益。
5. 严格的论文机制基线不能先获得 BRICS 增强条件。先建立无 BRICS 的邻接去噪机制基线，再加入披露的 BRICS 条件和门控；不能只用旧属性去噪模型调损失权重后称为论文对标。

## 对照与协议

- 首轮因果性较清楚的工程对照：相同新编码器从头训练、相同编码器邻接预训练、邻接预训练+BRICS统一跨边界处理、邻接预训练+BRICS条件门控。数据/预算/选模协议相同，报告参数差异；这属于论文机制启发下的受控比较，不是完整 MotiL 复现。
- 对比论文最终指标时，需另有完整 MotiL 三阶段基线，匹配训练/验证/测试定义、特征与监督预算；不能用仅 priming 的小语料试跑替代。
- 正文写 ZINC15 250K，CMPNN，扩散阶段 Adam、lr=3e-5、T=1000；bi-scaled 阶段写 batch=1024、50 epoch。当前试跑为 4096+512、10 epoch、AdamW/lr=1e-3、隐藏维度128等，存在多项差异。
- 正文描述三个随机种子 scaffold splits；本地既有审计记录了补充材料/公开代码的固定划分与初始化种子口径差异。必须预先选定并分别报告，不能把当前 OGB 固定 scaffold 划分上的种子波动当成论文的三次独立划分。详细差异见 MotiL_local/PAPER_PROTOCOL_CN.md。
