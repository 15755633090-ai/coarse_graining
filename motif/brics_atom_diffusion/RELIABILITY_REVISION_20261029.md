# 恢复诊断与检查点一致性修订

针对 010399c 的静态审查，保留原子级 epsilon MSE 训练目标和默认日程，补充以下工程与评估能力。没有启动大规模预训练或正式门控性能消融。

1. **恢复诊断**：三个相对时间区间、边界/内部组与元素/电荷/芳香性属性块交叉统计噪声 MSE、还原 x0 的 MSE和分类准确率；另有三个属性同时正确率。全部按误差/正确数与原子数累计，空组不填零。恢复质量与上下文依赖仍需要单独对照，不能用这些指标代替性质验证。
2. **消融语义**：no-motif-prior 明确定义为整套基序关系机制移除；两种状态都能全图传播，门控没有实际作用。结构上无效的参数冻结，区分实例化、优化和实际梯度参数量。
3. **检查点事务**：latest.pt 内嵌独立、不可被后续训练修改的最佳模型快照及全部恢复状态。先原子提交 latest，再导出 best/history。恢复只信任 latest 并检查版本一致性，修复陈旧/缺失/领先缓存；拒绝缺少权威快照的旧 latest 自动恢复。旧版正常完成运行不据此判为无效。
4. **日程追溯**：记录固定 beta 端点、T 及 alpha_bar_T，并显式标注 T 改变终点 SNR。T=1000 的 alpha_bar_T≈4.03583e-5，T=100≈0.364，不能称为纯时间分辨率对照。

## 验收证据

- `test_interfaces` + `test_diagnostics` 共 20 项测试通过。解析测试包括已知正确噪声的逐块完全恢复、独立属性块错误不被维度权重掩盖、构造错误类别后的准确率、分组分母与空组、端点日程、无效参数冻结、最佳快照不可变与版本拒绝。
- `runs/diagnostics_20261029/continuous`：ESOL 官方训练集合来源的小语料，train/valid 各 16 个分子，CPU、seed 7、2 轮，仅无标签恢复验证；未读取测试指标。
- 以下三种故障注入后恢复，模型权重、RNG 和训练历史均与连续运行逐值一致：
  - 首次 latest 已提交而 best 尚未导出，再人为放入 epoch 999 的错误 best/history 缓存；
  - 第 2 轮替换 latest 之前中断，保留第 1 轮提交；
  - 第 2 轮 latest 已提交而后续导出尚未进行时中断，恢复时无需重新训练该轮。
- acceptance.json 验证最终 best 导出均与 latest 内的权威快照一致。另跑通新检查点到 ESOL 的两轮小样本微调，仅验证集。

上述故障测试通过实际训练和文件保存执行，不只是正常保存后重载。新验收目录与旧 smoke_20261029 分开，旧结果保留原始源代码哈希，不能混用为本轮科学性能证据。
