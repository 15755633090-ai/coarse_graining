# 寻找完整成熟方法：本轮结果与可运行候选

本轮停止自行拼装神经模块，直接验证官方CheMeleon、官方丰富特征Chemprop、标准SVR和XGBoost。**找到的ESOL候选为规范化200维RDKit描述符＋标准RBF-SVR，验证RMSE0.772921；相比原从头均值0.787109约低1.8%。** 这是一次反复使用的验证划分上的小幅观察差距，不能称稳定突破。它不是新基序网络，也没有在FreeSolv上取得收益。

## 完整结果

所有数值都是原单位验证RMSE，越低越好；没有本轮测试集结果。

| 方法 | ESOL | FreeSolv | 记录 |
|---|---:|---:|---|
| 原自建从头模型（已有） | 0.787109±0.028044 | 本轮未运行 | 3种子参考 |
| 官方D-MPNN（已有） | 0.806182±0.011024 | 2.096518±0.132146 | 5种子参考 |
| 官方CheMeleon全参数微调 | 0.820503±0.015222 | 3.362486±0.047226 | 3种子，50轮 |

SVR不是随机初始化网络，不重复相同拟合伪造种子标准差。SVR及XGBoost的配置在训练集内部按规范分子分组交叉验证选择，任务验证集没有参与其内部参数选择或early stopping。但在观察前面方法失败后继续选择下一方法，属于适应性方法搜索，仍带有整体选择偏差，不能将最低验证值当作无偏性能估计。

FreeSolv没有得到改善，继续保留原有基线；不只呈现有利任务。官方模型与原模型的容量、输入、软件和训练预算不同，不能据此声称预训练、基序或某个组件的独立贡献。保留原默认模型，增加SVR为可使用的ESOL候选和后续比较基线。

## 为什么这次不同

这里没有发明新的融合层。采用完整已有方法和公开API，而不是把论文的模块名字放在一起。CheMeleon严格加载其[公开权重](https://zenodo.org/records/15460715)，核心源码与固定官方Chemprop2.2.3逐文件核对；完整负面结果见[CheMeleon协议](../official_chemeleon/METHOD_20261030.md)。丰富特征路径按[官方支持的描述符入口](https://chemprop.readthedocs.io/en/latest/extra_features_descriptors.html)运行，详见[预测方法协议](../official_chemprop_rich/METHOD_20261030.md)。

SVR直接学习由分子结构计算出的200维特征到目标性质的非线性映射，没有扩散、恢复任务或随机教师。C和gamma仅在训练集内选择，ESOL最终为C=10、gamma=scale、epsilon=0.1。没有把计算描述符当作性质标签，也没有用验证标签构造特征。

## 直接使用ESOL候选

本地已训练模型位于`motif/official_chemprop_rich/runs/comparison_20261030/esol/svr/model.joblib`。独立预测入口已在全部113条验证分子上与记录预测核对一致。

```powershell
.runtime/chemprop_gpu311/Scripts/python.exe -m motif.official_method_search.predict_svr --input-csv molecules.csv --output-csv predictions.csv
```

输入CSV默认含`smiles`列，输出`predicted_log_solubility`，数值单位沿用ESOL目标。工具不会覆盖已有输出文件。需要同一官方特征生成器及已记录依赖；本轮环境为Chemprop2.2.3、scikit-learn1.9.1、RDKit2026.9.1。完整依赖和源码身份在各运行provenance.json中。

为便于GitHub复核，发布`esol_svr_20261030.tar.xz`，内含此模型原文件和哈希验收记录；下载仓库后在项目根目录解包即可恢复上述路径。其他大检查点及特征缓存留本地、公开哈希；外部CheMeleon权重按固定Zenodo地址另取，不复制发布。

## 验收和限制

- ESOL和FreeSolv的训练/验证索引、SMILES、目标均与原统一数据入口逐条核对一致；分别为902/113和513/64条。
- 12组正式神经训练全部完成50轮；另有两组2轮流程检查，不混入性能均值。训练目标缩放只用训练集，选模分数与还原后的原单位预测对应。
- 对全部神经模型、SVR、两版Ridge和XGBoost预测CSV重新计算指标，核对样本顺序和目标。检查点回放、SVR模型恢复及独立推理均通过。
- 冻结Ridge最初有float32病态矩阵告警；相同数据、折和正则化候选换用float64后，差结果没有消失，不能归咎于舍入误差。标准化后验证特征最大绝对值分别约8616和1882，记录为诊断，不据此继续调尺度。
- XGBoost曾遇Windows中文路径的文件加载问题，随后使用官方原始字节序列化接口回放；保留修改前源码、原计划哈希和恢复记录，没有改变模型或CV配置。
- 外部CheMeleon预训练结构与本项目数据的精确交集未知，不宣称预训练无重叠。所有候选都未建立新的基序研究贡献，也未证明跨任务稳定增益。

机器可读汇总为`results_20261030.json`，验收为`acceptance_20261030.json`，全部执行源码快照为`frozen_sources_20261030.tar.xz`。失败方法不会从记录中移除。

该源码归档同时保留各运行原始CSV和plan.json的精确字节，包括Windows行尾，用于核对运行时原始SHA256。Git中便于阅读的文本采用LF行尾；核验原始运行数据哈希时应使用归档内版本，不把行尾转换误判为数据内容变化。
